# SimpleSchedule для iPhone

Веб-приложение: [открыть SimpleSchedule](https://simpleschedule-pwa.onrender.com). **16 октября 2026 года** сервер развёрнут на Render, настройки Supabase Auth и Resend SMTP сохранены. Отправка кода, реальный вход и синхронизация двух устройств пока не проверены.

Русскоязычный календарь с делами, цветными группами и расписанием ИРНИТУ. Веб-приложение устанавливается на главный экран iPhone из Safari. App Store, IPA и разработческая подпись Apple не нужны. Виджет iOS не предусмотрен.

Проект этой версии находится в ветке **`pwa-ios`**, в папке `PWA`. Сервер и интерфейс размещаются на одном HTTPS-адресе: **https://simpleschedule-pwa.onrender.com**. Ответ сервера `authConfigured=true` подтверждает наличие конфигурации, но не подтверждает правильность секретных ключей, доставку письма или успешный вход.

## Возможности

- Месяц, неделя с понедельника и день. Переключение сохраняет выбранную дату; есть стрелки, «Сегодня» и точный выбор даты.
- Дела с выполнением, заметками и пользовательскими группами. Удаление группы сохраняет её дела в «Без группы». Страница группы показывает все её дела.
- Отдельный режим расписания: импорт ИРНИТУ, все подгруппы в локальной базе, фильтрация выбранной подгруппы, ручные пары и домашние задания.
- Лабораторные работы отмечены жёлто-оранжевой рамкой, практики зелёной, остальные занятия синей; вид занятия также указан текстом.
- Локальная работа без регистрации. После первого успешного открытия и сохранения ресурсов приложением можно пользоваться без сети. Отправка кода, синхронизация и обновление сайта требуют интернета.
- Опциональный вход по одноразовому коду на email и синхронизация между экземплярами PWA. Конфликтующие правки не перезаписываются молча.
- Светлая, тёмная и системная темы, настройка фона, экспорт и восстановление локальных данных.

Подключение существующих нативных macOS/Windows к этому облачному протоколу — отдельная работа. Эта ветка не добавляет им синхронизацию и не меняет Windows.

## Установить на iPhone

1. Откройте **https://simpleschedule-pwa.onrender.com** в Safari.
2. Дождитесь загрузки календаря. В Safari нажмите **Поделиться → На экран «Домой» → Добавить**. В разных версиях iOS положение команды может отличаться.
3. Открывайте SimpleSchedule значком на главном экране. Срока действия подписи разработчика у такой установки нет.
4. Для нескольких устройств войдите с одной почтой через **Настройки → Синхронизация**. Если до входа вы создали локальные дела, выберите их объединение с аккаунтом.

Не удаляйте данные Safari как способ обновить приложение: это может удалить ещё не синхронизированные записи. Периодически делайте экспорт; браузерное хранилище не заменяет резервную копию.

## Пользоваться

В режиме **Дела** нажмите **Добавить**, укажите название, дату и при желании группу. Кружок слева отмечает выполнение. Нажатие на запись открывает редактор. Цветная кнопка группы открывает её страницу; повторное нажатие возвращает календарь.

В режиме **Расписание** откройте настройки ИРНИТУ, загрузите список институтов, выберите институт и учебную группу. Нажмите **Обновить расписание**. После загрузки выберите свою подгруппу: общие занятия и занятия выбранного номера остаются видимыми, переключение не требует повторного запроса сайта. **Все подгруппы** показывает все активные занятия.

Кнопка **Занятие** создаёт ручную пару. Окончание рассчитывается по длительности из настроек и доступно для ручного исправления. Домашнее задание и личные изменения сохраняются при повторном импорте. Неопубликованные дни не очищают прежние данные.

Обычная синхронизация выполняется после изменений и при возвращении в приложение. Автоматическое обновление расписания выбирается отдельно: вручную либо раз в 1/3/6 часов. Сервер выполняет его даже без открытого Safari, **если сервер работает и настроена очередь**; бесплатный спящий Render не гарантирует точный часовой цикл. Закрытый iPhone получит новые данные при следующем открытии и доступной сети.

## Уведомления — следующий этап

Сохранены настройки и требования: уведомления об изменениях сайта и напоминания за 5 минут по умолчанию, произвольное число минут, общий выключатель, отдельные типы, исключения по дисциплине и выбранной дате. **Отправка Web Push пока не реализована.** Эти настройки сами по себе не включают доставку на телефон.

Для закрытой PWA на iPhone потребуются серверный Web Push, установка на главный экран и разрешение пользователя. Нельзя гарантировать доставку ровно за выбранное число минут или без сети. Не использовать JavaScript-таймер закрытой страницы для напоминаний.

## Разработка

Нужны Node.js **22.12+**, npm и .NET SDK **10**. Зависимости закреплены в lock-файлах.

```sh
git clone --branch pwa-ios https://github.com/pouqwyggad1/SimpleSchedule.git
cd SimpleSchedule/PWA/client
npm ci
npm test
npm run dev
```

В другом терминале из `PWA/server`:

```sh
ASPNETCORE_ENVIRONMENT=Development PublicOrigin=http://127.0.0.1:5173 dotnet run --urls http://127.0.0.1:5080
```

Откройте `http://127.0.0.1:5173`. Dev-сервер перенаправляет `/api` на порт 5080. В development Service Worker отключён, поэтому офлайн-поведение проверяйте в production-сборке.

```sh
# Из PWA/client
npm run build
npx playwright install chromium webkit
npm run test:e2e
```

WebKit с размером iPhone проверяет браузерный интерфейс, но не заменяет установку и проверку на физическом iPhone. Для удалённого телефона нужен HTTPS: обычный HTTP по IP компьютера не обеспечивает установку/Service Worker как production.

## Развёртывание

Настройка Supabase, SMTP и Render: [DEPLOY.md](DEPLOY.md). Схема БД находится в `supabase`, API в `server`, интерфейс в `client`. Рабочий каталог Docker-сборки — `PWA`:

```sh
docker build -t simpleschedule-pwa PWA
docker run --rm -p 8080:8080 --env-file /путь/к/личному/server.env simpleschedule-pwa
```

Не сохраняйте секреты в Git, README, Vite-переменные или снимки экрана. Resend API-ключ настраивается как SMTP-пароль **в Supabase Auth**, а не в браузере.

В Supabase сохранены оба русских шаблона входа — **Confirm sign up** и **Magic Link** — из [emails/auth-code.html](emails/auth-code.html). Код состоит из 6 цифр и действует 10 минут. SMTP использует подтверждённого отправителя `noreply@notify.pouqwyggad123.shop`. Доставка, вход, обмен между устройствами и установка на физическом iPhone отложены; фактические результаты перечислены в [CHECKS.md](CHECKS.md).
