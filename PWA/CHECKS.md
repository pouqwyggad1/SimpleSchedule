## Ограничения фактической проверки

- UI-импорт в Playwright использует контролируемый API-ответ. Отдельно выполнен настоящий импорт одной недели через production backend локально. На Render подтверждён контрольный сценарий входа и двустороннего обмена делом; полная ручная приёмка всех пользовательских сценариев не завершена.
- На физическом iPhone установка на главный экран, системное вытеснение хранилища и длительная фоновая работа пока не проверены.
- SMTP и реальные вход/двусторонний обмен проверены в указанном контрольном сценарии. Часовой цикл Render при закрытых клиентах не проверен; встроенный worker работает только пока сервер запущен. Агент не запрашивал новые реальные коды и не читал OTP/токены; пользователь вводил коды самостоятельно.
- Историческое состояние до реализации Web Push: сохранялись только предпочтения. Нет обещания уведомлений без сети или точного времени показа.
- Локальный Docker daemon не запущен. Сам контейнер успешно собран и запущен на Render; полный набор сценариев на облачном сервисе ещё не пройден.
- Доступные номера подгрупп из неактивных альтернатив сохраняются локально при ручном импорте; новое устройство выводит номера из синхронизированных активных занятий и своей выбранной подгруппы. Для полного каталога на нём можно обновить расписание.
- Формат локального хранения PWA отдельный; нативные macOS/Windows пока не подключены к облачной синхронизации.
