Ядро дополнительно проверяет запись и очередь одной транзакцией, отказ IndexedDB без осиротевшей операции, неизменные ID повторных запросов, цепочки правок при запросе, устаревший ответ после новой ревизии, полевые конфликты/удаление, гостевое объединение со снимками, размер пакета UTF-8 и проверку ожидаемого аккаунта. Отдельные регрессии подтверждают цепочки «отмена источником → повторная публикация», «отмена → удаление пользователем → повторная публикация», сохранение отмены в резервной копии и отсутствие отмены при неизвестном периоде. Backend сравнивает `X-SimpleSchedule-Account` с пользователем защищённой сессии: смена аккаунта в соседней вкладке не должна отправлять старую очередь новому владельцу.

## Ограничения фактической проверки

- UI-импорт в Playwright использует контролируемый API-ответ. Отдельно выполнен настоящий импорт одной недели через production backend локально. Сервис Render создан, но живой импорт и пользовательские сценарии на нём отложены по просьбе пользователя.
- На физическом iPhone установка на главный экран, системное вытеснение хранилища и длительная фоновая работа пока не проверены.
- SMTP, параметры Auth и секретные переменные сервера сохранены. Живой email OTP, правильность ключей при реальном запросе, полный обмен двух авторизованных устройств и часовой цикл Render пока не проверены. Пользовательские аккаунты и письма при тестах базы не создавались; после настройки почты код входа не запрашивался.
- Web Push пока не отправляется: реализовано сохранение предпочтений будущего этапа. Нет обещания уведомлений без сети или точного времени показа.
- Локальный Docker daemon не запущен. Сам контейнер успешно собран и запущен на Render; полный набор сценариев на облачном сервисе отложен по просьбе пользователя.
- Доступные номера подгрупп из неактивных альтернатив сохраняются локально при ручном импорте; новое устройство выводит номера из синхронизированных активных занятий и своей выбранной подгруппы. Для полного каталога на нём можно обновить расписание.
- Формат локального хранения PWA отдельный; нативные macOS/Windows пока не подключены к облачной синхронизации.

## Повторить проверки

```sh
cd PWA/client
npm ci
npm test
npm run build
npx playwright install chromium webkit
npm run test:e2e
```

Сервер: `dotnet run --project PWA/server.tests/SimpleSchedule.Pwa.Tests.csproj -c Release` из корня репозитория. SQL/HTTP/concurrency-проверки и параметры временного кластера описаны в [SUPABASE_SETUP.md](server/SUPABASE_SETUP.md).
