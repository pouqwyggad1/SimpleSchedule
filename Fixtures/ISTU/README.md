Датированный маршрут подтвержден ссылками официального read-only календаря сайта. Запросы `?date=...` не выбирают неделю; рабочий формат — последний сегмент `DD.MM.YYYY/`. Для загрузки недели достаточно этого маршрута; JavaScript и календарный Ajax в приложении не нужны.

Важная регрессия: текст «Показана неделя» и правило из `https://www.istu.edu/raspisanie/pamyatka` не определяют фактически активные карточки сайта. В HTML 12–18.10.2026 текст говорит «нечетная», но внешний блок имеет класс `sch-list-week-even`; официальный CSS делает карточки `.week-odd` серыми. На соседней неделе подпись и классы меняются на противоположные. Парсер использует единственный внешний активный класс, как сайт, исключает противоположную альтернативу и `card-unactive`, а при отсутствии/неоднозначности этого класса безопасно отказывает. Вычисления от 1 сентября или ISO-недели не применяются: они ранее давали именно серые альтернативы.

Номера подгрупп собираются из карточек выбранной группы обеих альтернатив, чтобы выбор в настройках не зависел от активной недели. В список занятий попадают только активные карточки, но сразу для всех их подгрупп. Фильтрация пользовательского выбора происходит после импорта, локально. Тесты проверяют конкретные 13/14 октября, соседнюю неделю, все номера подгрупп, исключение чужих номеров, постоянство sourceID при изменении времени, границы сентября и календарного года.

Частичная публикация допустима. Диапазон «Начало/Окончание действия» задаёт границы недели, но не подтверждает отсутствующие блоки дней. При непустой неделе `coveredDays` содержит только реально опубликованные `.sch-list-day`, включая явные пустые дни: у ИСТб-26-1 их пять, у ИСИб-23-1 шесть. Отсутствующие дни не считаются пустыми, поэтому импорт не удаляет ранее сохранённые занятия за неизвестный остаток недели. Только полностью пустой блок недели с корректным явным диапазоном подтверждает весь этот диапазон. Даты и диапазон обязаны находиться внутри запрошенной недели; неизвестный текст ошибки в блоке недели или пустого дня отклоняется. Синтетические регрессии проверяют публикацию пн–ср при шапке пн–вс, отсутствие покрытия чт–вс и сохранение покрытия явно пустой среды.

Ответ об отсутствии публикации распознаётся отдельно как `ISTUParserError.noPublishedSchedule` и не создаёт покрытия каких-либо дат. Проверяются цельный единственный `main.page-content`, информация о группе/институте/курсе и точное официальное сообщение в единственном абзаце; постороннее содержимое, неизвестный текст ошибки, сообщение вне `main` и оборванный контейнер остаются ошибкой разметки. Встроенный HTML tidy удаляет HTML5-элемент `main`, поэтому перед DOM-разбором его граница сохраняется как помеченный `div`. JavaScript не выполняется, ресурсы не загружаются.
