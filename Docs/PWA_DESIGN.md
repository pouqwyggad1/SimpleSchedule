# SimpleSchedule: оформление PWA

Цель: быстро увидеть свой день, с привычной иерархией календаря и доступными одной рукой действиями. React PWA использует CSS-приближение Liquid Glass, а не нативный рендеринг UIKit. Данные и механика синхронизации при редизайне не меняются.

## Уточнение по скриншотам пользователя — единое стекло

Все кнопки действий, выбор даты, метки групп, вкладки настроек и плавающие панели используют один нейтральный прозрачный материал с тонким бликом и размытием. При обычных 35% настройки alpha заливки уменьшена примерно с 0.82 до 0.33; значение0 сохраняет непрозрачный вариант. Обычные, основные и выбранные действия имеют одинаковый основной цвет: #1C1C1E в светлой теме, #F5F5F7 в тёмной. Выбор отмечают подложка, вес шрифта и контур. Цвета содержимого (сегодня, группы, виды занятий, ошибки) сохраняют смысл. Геометрия основных панелей не меняется. На телефоне пять разделов настроек расположены в сетке, поэтому их содержимое не сдвигается по горизонтали; длинные поля ограничены шириной листа.

Контраст проверяется на нейтральном фоне и поверх карточек; усиленный контраст и уменьшение прозрачности возвращают непрозрачный материал. Карточки не получают стекло.

## Основания и решения

- `materials.md › Liquid Glass`: “Don’t use Liquid Glass in the content layer.” Поэтому карточки дел и занятий — непрозрачный слой содержания; стекло — только панели управления, меню и шапки листов. [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials).
- `accessibility.md › Mobility`: “Offer sufficiently sized controls.” Основные касания не меньше 44×44 CSS px, включая метки выполнения; видимый кружок может быть меньше области касания.
- `typography.md › Using system fonts`: “Consider using the built-in text styles.” Системный шрифт устройства; мобильный текст 17, вторичный 15, подписи 13, компактные подписи календаря 11. Заголовки 34/28/22. Размеры в rem и без запрета масштабирования.
- `motion.md › Best practices`: “Add motion purposefully, supporting the experience without overshadowing it.” Движение выбранного сегмента, короткое касание и появление/закрытие листов; без фоновых анимаций. [Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion).
- `dark-mode.md › Best practices`: обе темы следуют системе по умолчанию; ручной выбор сохранён по прямому требованию пользователя. Уменьшение движения/прозрачности и повышенный контраст имеют отдельные состояния.

## Токены до реализации

| Роль | Светлая | Тёмная |
|---|---|---|
| Основной фон | #F2F2F7 | #000000 |
| Содержимое | #FFFFFF | #1C1C1E |
| Основной текст | #1C1C1E | #F5F5F7 |
| Вторичный текст | #636366 | #AEAEB2 |
| Кнопки, символы, ссылки и выбор | #1C1C1E | #F5F5F7 |
| Сегодня/ошибка | #C52A23 | #FF6961 |

Контраст на непрозрачной карточке: основной текст 17.01/15.63; вторичный 5.99/7.69; кнопки используют тот же основной контрастный цвет, без синей заливки и разноцветных надписей. Окончательные стеклянные поверхности проверять на фоне содержимого, а не только по токенам.

Лабораторная — охристый/жёлтый, практика — зелёный, остальное — синий. Текст вида занятия сохраняется, чтобы цвет не был единственным различием.

## Компоновка

```text
Компактная                         Обычная
SimpleSchedule       облако ⚙      SimpleSchedule   [Месяц Неделя День]   облако режим ⚙
       [Месяц Неделя День]          [обновить — слева от сегментов, без сдвига]
< Сегодня >       [точная дата]     < Сегодня > группы          группы дата +
группы                             Октябрь 2026
Октябрь 2026                       календарь                  выбранный день
календарь                          календарь                  карточки
выбранный день / карточки
                                  служебная строка
[ Дела | Расписание ]        (+)
```

Характерный элемент — нижняя плавающая стеклянная капсула на iPhone, отдельная круглая кнопка добавления и красный круг сегодняшнего дня. На широком экране выбор месяца/недели/дня остаётся точно по центру при переключении режимов. Размеры кнопок одинаковы в делах и расписании.

Критика плана: стекло на белом фоне может быть незаметно; глубину дают тонкий блик, мягкая тень и прокрутка содержимого под панелью, а не декоративные цветные пятна. Узкая сетка месяца не вмещает весь временной диапазон крупным текстом: на телефоне остаётся число занятий, подробное время находится в выбранном дне и доступном названии ячейки. Длинные формы прокручиваются внутри листа и не скрывают его действия.

## Проверка

Ожидаются WebKit/Chromium, светлая/тёмная/системная тема, 320–1440 px, отсутствие горизонтального переполнения, размеры целей, контраст, модальные формы и клавиатура, reduced motion, офлайн и прежние сценарии авторизации/синхронизации. Автоматические браузерные проверки дополняются визуальным осмотром; физический iPhone и VoiceOver не заменяются эмуляцией. В сетке календаря на ширине 320 px цели дня меньше 44 px, но больше минимальных 28 px; основные действия сохраняют 44 px.
