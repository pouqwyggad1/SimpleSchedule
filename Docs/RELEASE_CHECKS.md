## Архив: проверки выпуска 1.0.0

Дата: **16 октября 2026 года**. Среда: macOS 27.0.1 на Apple Silicon, Swift 6.3.2, Command Line Tools и SDK macOS 26.5. Минимальная система приложения — macOS 27.0.

## Приложение

- Universal-сборка основного приложения и встроенной XPC-службы прошла; архитектуры — arm64 и x86_64.
- Аудит `scripts/validate-offline.sh` прошел: подписи, plist, настройки targets, встраивание службы и разрешения App Sandbox.
- Основной процесс и исходный target виджета не имеют сетевых разрешений. Только отдельная XPC-служба имеет исходящее сетевое разрешение; входящего сетевого разрешения нет.
- Последний полный `scripts/test.sh` прошел с 21 828 утверждениями. После граничных исправлений отдельно повторены затронутые наборы: парсер — 80, контроллер импорта — 111. Последние результаты всех 11 наборов суммарно — **21 862 утверждения**; это не второй полный запуск всех наборов.
- Реальная цепочка ИРНИТУ → sandboxed XPC → парсер → временное локальное хранилище проверена: институты и группы, активные альтернативы расписания, метаданные подгрупп, автоматическое окончание занятия, повторный импорт без дублей, сохранность ручных полей и домашнего задания.
- В интерфейсе проверены месяц, неделя и день, единая дата, стабильная геометрия двух режимов, три цвета рамок занятий, формы и выбор подгруппы. Импорт неполного периода проверен тестами; официальный ответ о неопубликованной неделе также проверен реальным запросом без ошибки и очистки.

## Что не подтверждено

- Запуск Intel-сборки на физическом Intel Mac; проверены компиляция, Mach-O и подписи.
- Установка загруженного DMG на чистом другом Mac. Выпуск имеет локальную **ad-hoc подпись**, без Developer ID и нотариального заверения Apple; Gatekeeper может потребовать подтверждение или запретить запуск.
- Установленный виджет рабочего стола. Готовые DMG собраны через CLI и **не включают WidgetKit extension**. Исходный Xcode-проект содержит этот target; для полной сборки и регистрации нужны полный Xcode и подходящая Apple Team с App Groups.
- Полный физический запуск без сети, обрыв сети во время обновления, runtime перенаправления и предела ответа 4 МБ. Ограничения проверены кодом и изолированными тестами; обычные HTTPS-запросы и завершение XPC проверены реально.
- Переключение рабочих столов жестом, повторный физический клик по значку строки меню, внешние углы родительского окна за открытым листом, настоящий выход из учетной записи и вход для автозапуска.

Эти ограничения не скрываются за успешной компиляцией или тестами. Сценарии для проверки на устройстве находятся в [ручном чек-листе](Ручная%20проверка.md).
